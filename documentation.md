## Documentation

### Metadata and Document Information (teiHeader)
   
`<teiHeader>`: Contains the metadata for the TEI document, including descriptive information about the title, author, publication, and revisions.
`<fileDesc>`: Describes the file metadata.
`<titleStmt>`: Contains the title and author of the work.
`<title>`: The title of the work ("The Selfish Giant").
`<author>`: The author of the text (Oscar Wilde).
`<respStmt>`: Identifies who encoded or edited the text.
`<resp>`: Describes the action ("Encoded by").
`<persName>`: Marks the name of the editor.
`<publicationStmt>`: Contains information about the publication for which the encoding was done.
<p>: Describes, in our case, the exercise or event related to the encoding process.
<sourceDesc>: Describes the source of the text.
<bibl>: Describes the bibliographic details of the source.
<author>: Author of the source.
<title>: Title of the source text ("The Happy Prince and Other Tales").
<publisher>: Publisher of the source.
<pubPlace>: Place of publication.
<date>: Date of publication.
<revisionDesc>: Describes changes made to the XML-TEI file.
<change>: Records specific changes and edits made, with a date and description.
